# Side-B

纯文字论坛调查游戏。

- 在线游玩：通过 GitHub Pages 打开仓库对应页面。
- 建议第一次游玩不要查看 `app.js` 或仓库历史，以免剧透。
- 进度保存在浏览器本地存储中；清除站点数据、无痕模式或更换浏览器可能导致存档消失。
- 手机和桌面浏览器均可游玩。

## GitHub Pages

在仓库 **Settings → Pages** 中：

1. Source 选择 **Deploy from a branch**
2. Branch 选择 **main**
3. Folder 选择 **/ (root)**
4. 保存

几分钟后即可通过 `https://你的用户名.github.io/仓库名/` 访问。
